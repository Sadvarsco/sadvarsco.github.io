How it works

Two rulesets

  • Meta Madness — ten heroes are banned in every game of every series (Anduin, Blaze, Brightwing, Chromie, Dehaka, Hanzo, Hogger, Johanna, Sylvanas, Valla), then each series adds ten more bans in a 1–2–2–2–2–1 order.
  • Competitive — no automatic bans. Just the standard triple-ban tournament draft, plus the single-use rule.

The single-use rule

In both modes, once a hero is picked in any game they are dead for the rest of the series — for both teams. Bans made inside a game only apply to that game.

Running a draft

  • The status bar tells you whose turn it is and whether it is a ban or a pick. Click a hero portrait and it advances automatically.
  • If the teams draft out of order, hit an Override button — the next click uses that team and action instead, then it goes back to following the script.
  • Undo steps back one action. Next game clears the per-game bans but keeps every hero that has already been played locked out.

Putting it on stream

See OBS-SETUP.md. Short version: add overlay.html as a Browser Source, and add this page as a Custom Browser Dock inside OBS. Because they run in the same browser they share state automatically — clicking a hero in the dock updates the overlay live.
